The app is structured as a Swift Package with `Sources/App` bootstrapping `NSApplication` and dispatching lifecycle to feature modules under `Sources/Features` (Clipboard, Keyboard, Settings, Translator, Cleaner). Each feature declares itself via the shared `Shared/Core/Feature.swift` protocol so the `AppCoordinator` can discover and start them. Cross-cutting concerns live in `Shared/` — settings persistence (`SettingsStorage` + per-module `*Settings`), unified logging (`SKeyLogger`), localization (`LocalizationService`), permissions, status bar, and shortcut primitives — and are consumed uniformly by every feature. The Keyboard feature additionally bridges to native code through `CSKey/include/skey.h` and a bridging header, while Resources bundle icons, localized strings, and `Info.plist`. Build and release tooling lives in `build.sh`, `release.sh`, and `Package.swift`, and standalone scripts under `scripts/` exercise individual features outside the app process.
