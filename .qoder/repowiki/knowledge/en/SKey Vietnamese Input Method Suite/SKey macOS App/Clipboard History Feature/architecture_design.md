ClipboardFeature is the public entry point implementing the shared `Feature` protocol; it owns a singleton `ClipboardStore`, wires `ClipboardMonitor.shared` to push captured pasteboard content into the store via async tasks, and constructs the `ClipboardHistoryPopupController` on the main thread for UI. The Services layer (capture, storage, retention, search ranking) is isolated behind `ClipboardStore`, which the UI consumes through a read-only interface, while the UI layer drives user actions back through the feature's `togglePopup`/`showPopup`/`hidePopup` methods. Paste operations are funneled through `handlePaste`, which loads payload data from storage and injects a synthetic Cmd+V via CoreGraphics events so the target app receives a native paste. Feature lifecycle (`start`/`stop`) gates behavior on `AppSettings.shared.clipboard.isEnabled`, making the feature pluggable alongside other features in the host app.
