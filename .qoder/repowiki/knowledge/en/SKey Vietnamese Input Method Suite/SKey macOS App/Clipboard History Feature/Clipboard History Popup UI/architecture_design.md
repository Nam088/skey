The module follows an MVVM layout split across three subfolders. `ViewModels/` holds a single `@MainActor ObservableObject` (`ClipboardHistoryViewModel`) plus three focused extensions (`+Actions`, `+Display`, `+Navigation`) that encapsulate mutations, derived state (pinned/unpinned ordering, display order, index map), and navigation; it owns `NSCache` instances for images, app icons, color swatches, and attributed titles, listens to `ClipboardStore.events` via async streams, and drives all `@Published` state consumed by views. `Views/` is purely SwiftUI: `ClipboardHistoryContentView` composes header, pinned section, scrollable list body, footer, and clear-confirmation overlays; supporting views (`ClipboardListItemView`, `ClipboardSlideoutView`, `PasteStack*`, `ClipboardPreviewItemView`, etc.) render individual rows and the slideout preview. `Controllers/` bridges AppKit and SwiftUI: `FloatingPanel` is a borderless, non-activating `NSPanel` hosting the root SwiftUI view via `NSHostingView`; `ClipboardPopupController` owns the panel lifecycle, computes popup origin relative to the status bar or mouse, installs local/global `NSEvent` monitors to close on outside clicks, and dispatches keyboard shortcuts (arrows, Enter, Escape, Cmd+Opt+Shift backspace, Ctrl chords) to the ViewModel; `ClipboardPreviewPanel` hosts the side preview popover. A shared `ClipboardPopupUI.swift` centralizes design constants (widths, heights, corner radius, item height), a lightweight `Throttler` for hover-driven preview, a `ColorImage` helper, and a `VisualEffectView` NSViewRepresentable used throughout the UI. Dependency direction is one-way: Controllers → ViewModels → Views, with ViewModels depending only on the external `ClipboardStore` and `AppSettings`.
