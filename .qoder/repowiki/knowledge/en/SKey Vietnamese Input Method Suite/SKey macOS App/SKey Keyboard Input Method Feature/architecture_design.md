KeyboardFeature is the feature entry point that implements the app's `Feature` protocol: on `start()` it sets itself as `EventTapManagerDelegate`, loads preferences from `AppSettings.shared.keyboard`, and boots `EventTapManager`. The three sub-packages form a one-way data flow — `EventHandling/` captures raw CGEvent taps and runs them through `TypingPipeline` stages (`KeyInterceptor` → `KeyEventSender`), which call into `Engine/` (`SKeyEngine` / `MacroEngine` / `InputMethod`) to apply Telex/VNI/VIQR rules and macro expansion; the resulting Unicode string plus backspaces are then dispatched by `Context/` (`AccessibilityContextReader` + `ContextRecomposer` + `VietnameseDecomposer`) into the active app via Accessibility APIs. `Models/ExcludedApp` and `Models/MacroItem` are shared data types consumed by both Engine and EventHandling. `KeyboardFeature` also bridges UI (menu items, status icon) with runtime state by mutating `EventTapManager.shared.engine` setters whenever preferences change, and handles smart app-switch language toggling on focus changes.
