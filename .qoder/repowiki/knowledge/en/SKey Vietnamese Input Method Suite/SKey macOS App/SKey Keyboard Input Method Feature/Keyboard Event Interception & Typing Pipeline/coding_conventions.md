- Events generated by SKey are tagged with the `eventMarker` constant in `eventSourceUserData` and explicitly skipped at the top of the pipeline to prevent feedback loops.
- Hot-path code avoids heap allocation by reading Unicode characters from `CGEvent` into stack-allocated `UniChar` buffers via `withUnsafeTemporaryAllocation`.
- Cross-thread UI/state updates (UserDefaults writes, delegate callbacks, menu/UI toggles) are dispatched onto `DispatchQueue.main.async` from the tap thread to avoid KVO/disk flush on the event loop.
- Critical shared mutable state (e.g. `isVietnamese`, tap runloop/thread references) is guarded by `os_unfair_lock` rather than higher-level locks, reflecting the sub-microsecond latency requirement of the hot path.
- Interceptors communicate decisions exclusively through the `InterceptorResult` enum (`passThrough` / `swallowed`), keeping each stage's side effects isolated from downstream consumers.
- Key classification uses a precomputed static lookup table (`KeyClassifier.lut`) indexed by `CGKeyCode` value, with fast-path branches for function/media, navigation, backspace, and word-break categories.
