The module is organized around a clear input→process→output flow with three layers:

- **Event capture layer** (`EventTapManager.swift`): A singleton that owns the CoreGraphics `CGEventTap` lifecycle on a dedicated high-priority thread hosting its own `CFRunLoop`. It creates the tap (falling back from `.cghidEventTap` to `.cgSessionEventTap`), starts/stops it, and forwards every captured event to the pipeline. Language state (`isVietnamese`) is protected by an `os_unfair_lock` and persisted on the main thread.
- **Pipeline layer** (`Pipeline/TypingPipeline.swift`, `Pipeline/KeyInterceptor.swift`): Implements a Chain of Responsibility via the `KeyInterceptor` protocol and `InterceptorResult` enum (`passThrough` / `swallowed`). `TypingPipeline` is a single concrete interceptor that stages processing: self-event detection (SKEY marker), mouse clicks, modifier-only shortcuts, configurable hotkeys (language toggle, clipboard, cleaner, AI, ⌥T translate), app exclusion bypass, English-mode macro expansion, and finally Vietnamese composing via `SKeyEngine`. Fast-path classification uses `KeyClassifier` over a static lookup table.
- **Output layer** (`KeyEventSender.swift`): Injects synthesized key events back into the system using `CGEventSource(.hidSystemState)`, with a special-case path for Spotlight that uses direct Accessibility replacement. All injected events are stamped with the SKEY marker so they are ignored by the pipeline.
- **Shared constants** (`KeyConstants.swift`): Centralizes Carbon virtual key codes, timing delays, the SKEY event marker (`0x534B_4559`), and the `KeyCategory` / `KeyClassifier` lookup table used throughout the hot path.

Dependency direction is strictly one-way: `EventTapManager` → `TypingPipeline` → `KeyEventSender` + `SKeyEngine`/`MacroEngine`/`ContextRecomposer`; none of these types depend back on the manager. Cross-cutting concerns (settings, focus observation, accessibility) are accessed via shared singletons rather than passed in.
