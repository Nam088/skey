Three cooperating sub-areas form this leaf:
- `Resources/` is a standard macOS app bundle payload: `Info.plist` declares the app as an LSUIElement (`com.nam088.skey`, APPL) with Vietnamese as default localization plus English, lists required Accessibility and Input Monitoring usage descriptions, and points to `AppIcon.icns`. Localized user-facing text lives in `en.lproj` and `vi.lproj` `Localizable.strings` alongside a unified `Localizable.xcstrings` catalog. Vector assets under `assets/` include multiple logo variants and a preview HTML page.
- `Package.swift` defines the SwiftPM package `SKey` targeting macOS 26+, producing one executable target that depends on a C module `CSKey` (from `Sources/CSKey`) and links against Cocoa, ApplicationServices, Carbon, SwiftUI, CryptoKit and sqlite3, while pulling in a prebuilt Rust library `-lskey` from `../../port/target/release`. The `../Resources` directory is registered via `.process()` so it becomes part of the built product.
- `scripts/` contains self-contained Swift executables (each with its own `@main`) and thin shell runners that compile them with `swiftc -parse-as-library` into `/tmp/*_bin`, invoke them, and tail `/tmp/skey.log`. They exercise the same `SKeyEngine` / `VietnameseDecomposer` APIs used by the main app — recomposition, Yandex translation/live typing, Spotlight phrase/word tests, cross-app switching, shortcut handling, and security/app-exclusion checks — serving as a local test harness outside the Xcode build.
