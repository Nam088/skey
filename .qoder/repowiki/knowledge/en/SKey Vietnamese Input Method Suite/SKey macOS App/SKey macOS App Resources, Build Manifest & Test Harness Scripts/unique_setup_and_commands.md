Run individual feature tests via the paired shell scripts (e.g. `./run_yandex_test.sh`, `./run_spotlight_test.sh`, `./run_context_recomposer_test.sh`, `./run_app_exclusion_test.sh`); each script compiles its corresponding `*.swift` tester with `swiftc -parse-as-library` into `/tmp/<name>_bin` and then tails `/tmp/skey.log`. Regenerate the app icon by running `swift generate_app_icon.swift` from the project root, which draws the logo into an `AppIcon.iconset` and invokes `iconutil -c icns` to produce `Resources/AppIcon.icns`.
