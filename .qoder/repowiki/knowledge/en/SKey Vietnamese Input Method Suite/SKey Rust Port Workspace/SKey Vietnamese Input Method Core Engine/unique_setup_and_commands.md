Builds are feature-gated: default enables `testkit` and `alloc`; omitting `alloc` removes macro/keymap support and keeps the engine fully stack-only. The `large-macro-table` feature exists for builds that need bigger macro tables. Tests include a golden-diff harness (`tests/golden.rs` reading `golden_hashes.in`) used to maintain byte-for-byte parity with the original C++ engine via the sibling `port/oracle` differential harness.
