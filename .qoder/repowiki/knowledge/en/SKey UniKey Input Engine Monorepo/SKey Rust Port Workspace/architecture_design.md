The `port/` directory is a Cargo workspace (`resolver = "2"`) whose members — `skey-core`, `skey-capi`, `skey-cli`, `difftest` — are wired together by a top-level Makefile. `skey-core` implements the no_std Vietnamese input engine; `skey-capi` exposes it via the original UniKey C ABI (both legacy global-state and new context-based multi-instance variants) so the C++ oracle can link against either the native C++ engine or the Rust library through the same symbol surface. The `oracle/` harness compiles the original C++ sources into `oracle/oracle` and also into `oracle/oracle_rust` (linked against `target/release/libskey.a` with `-DRUST_BACKEND`) to drive end-to-end ABI equivalence. `tablegen/` regenerates `skey-core/src/phonetics/tables.rs` and `lexi_consts.rs` from the C++ source via a compiled `dump` binary plus Python scripts. `difftest/` drives both oracles over shared stdin protocols to sweep keystroke/keymap/macro spaces and soak-test them, while `bench/` compares performance of the C++ and Rust builds on identical corpora. A single `make verify` target chains sweep, soak, macrosweep, keymapsweep, quicksweep, capi-check, ctx-check, portability checks, and cargo tests as the canonical correctness gate.
