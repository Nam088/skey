`make all` builds the C++ oracle, the Rust libraries, and the RUST_BACKEND oracle variant; `make sweep|soak|macrosweep|keymapsweep|quicksweep|ctx-check` run differential tests against the C++ reference; `make capi-check` reruns macro/keymap sweeps driving the Rust engine exclusively through the C ABI; `make golden` re-freezes `skey-core/tests/golden_hashes.in`; `make verify` runs the full correctness pipeline; `make bench-compare` benchmarks C++ vs Rust on an identical corpus.
