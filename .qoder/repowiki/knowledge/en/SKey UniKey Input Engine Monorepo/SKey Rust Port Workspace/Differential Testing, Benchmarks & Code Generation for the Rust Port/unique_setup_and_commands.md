Run differential testing with `python3 sweep.py` (and the sibling `*_sweep.py` scripts) from `port/difftest/`; run performance comparison with `python3 compare.py` from `port/bench/` (reads `BENCH_CORPUS`, `BENCH_ROUNDS`, `BENCH_REPEATS` env vars). Regenerate tables by running `make -C port/tablegen` which invokes `dump.cpp` and `gen_lexi.py` to rewrite `tables.rs` and `lexi_consts.rs`.
