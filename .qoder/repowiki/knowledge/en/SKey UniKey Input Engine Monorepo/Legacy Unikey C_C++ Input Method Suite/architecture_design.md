The top-level `src/Makefile.am` drives a layered autotools hierarchy that builds each subdirectory as an independent library or binary in a fixed dependency order: low-level primitives (`byteio`, `vnconv`) first, then the core engine (`ukengine`), followed by the thin C++ facade (`ukinterface`), the XIM client stack (`IMdkit`), the XIM server bridge (`xim`), the standalone X11 GUI (`gui`), and conditionally the GTK IM module (`unikey-gtk`). Cross-child wiring is achieved through shared headers and duplicated synchronization helpers: `uksync.{c,h}` is copied into `gui`, `xim`, and `unikey-gtk` to provide process-local state sharing between the GUI/XIM processes and the engine, while `ukinterface` exposes a C++ wrapper around `ukengine` consumed by both `gui` and the GTK bridge. The `IMdkit` layer is reused by both the `xim` server implementation and the `gui` application to speak the XIM protocol, and `vnconv` is linked by the engine and GUI for encoding handling.
