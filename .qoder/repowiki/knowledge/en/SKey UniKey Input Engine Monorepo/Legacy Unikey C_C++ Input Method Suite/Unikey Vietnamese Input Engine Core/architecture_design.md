The module is a flat autotools-based static library (`libUnikey.la`) built from `Makefile.am`, depending on sibling libraries `../vnconv` and `../byteio`. It centers on three cooperating subsystems: (1) `ukengine.cpp/.h` defines the `UkEngine` class that orchestrates keystroke buffering, tone/hook/roof processing, Telex/VNI/VIQR/Microsoft-Vietnamese/Simple-Telex mode dispatch, word-boundary detection, and output emission; it owns a process-shared `UkSharedMem` struct holding options, an embedded `UkInputProcessor`, a `CMacroTable`, and per-process state. (2) `inputproc.cpp/.h` provides `UkInputProcessor`, which maps raw `keyCode`s into typed `UkKeyEvent`s using built-in mapping tables (`TelexMethodMapping`, `VniMethodMapping`, `VIQRMethodMapping`, `MsViMethodMapping`, `SimpleTelexMethodMapping`) and supports runtime replacement via a 256-entry key map or user-defined IM. (3) `mactab.cpp/.h` implements `CMacroTable`, a fixed-capacity in-memory macro store with file load/save, used to expand typed sequences into text snippets. Supporting headers define shared vocabulary: `keycons.h` declares `UkInputMethod`, `UnikeyOptions`, `UkOutputType`, and Win32-only `UnikeySysInfo`; `vnlexi.h` enumerates Vietnamese lexical primitives (`VnLexiName`, `VowelSeq`, `ConSeq`); `usrkeymap.cpp/.h` exposes `UkLoadKeyMap` / `UkLoadKeyOrderMap` / `UkStoreKeyOrderMap` for persisting user key remappings. Dependency direction is one-way: `ukengine` → `inputproc` → `keycons`/`vnlexi`; macros and user keymaps are loaded at startup and injected into the shared memory region so multiple processes can share the engine state without pointers.
