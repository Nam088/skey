The module is organized as a flat collection of feature-agnostic sub-packages under `Sources/Shared/` that are consumed by higher-level app modules through well-defined singletons and protocols:
- `Core/Feature.swift` defines the `Feature` protocol (`id`, `name`, `isEnabled`, `enable()`, `disable()`, `start()`, `stop()`, `buildMenuItems()`) with default `enable`/`disable` forwarding to `start`/`stop`, establishing the pluggable capability contract used by the status bar.
- `Settings/` is the central state hub: `SettingsStorage` provides a thread-safe in-memory cache over `UserDefaults` backed by an `os_unfair_lock` with async background writes on a utility queue; `AppSettings` composes typed setting modules (`KeyboardSettings`, `ClipboardSettings`, `MacroSettings`, `GeneralSettings`, `ShortcutSettings`, `TranslatorSettings`) via `SettingsModule`; `SettingsBackupManager` handles backup/restore. Settings flow is one-directional: consumers read from `AppSettings.shared`, which reads from `SettingsStorage.shared`.
- `Logging/SKeyLogger.swift` wraps Apple's `os.Logger` with an in-memory `LogStore` and optional async file writer to `/tmp/skey.log` (2 MB rotation, 0600 POSIX permissions), gated behind `#if DEBUG` and `AppSettings.shared.general.isDebugMode`. Global convenience functions `SKeyLog.debug/info/warning/error` funnel into it.
- `Localization/LocalizationService.swift` exposes a singleton `ObservableObject` that switches between `vi`/`en` bundles, posts `languageDidChange`/`skeyLanguageDidChange` notifications, and provides a `StringKey` enum plus `L10n()` global helpers for strongly-typed localized strings with Vietnamese fallback.
- `Services/` contains platform helpers — `PermissionsService` (AX/EventTap checks), `LaunchAtLoginService`, `TextTransformService`, `UpdateCheckerService`, `AppFocusObserver` — all exposed as singletons wrapping low-level Cocoa/Carbon APIs behind simple synchronous methods.
- `UI/StatusBarManager.swift` owns the `NSStatusItem`, builds a grouped menu from injected `Feature`s, renders a dynamic V/E keycap icon, and wires language changes, tools, and quit actions.
- `Shortcuts/KeyShortcut.swift` models shortcuts (`KeyShortcut`, `ShortcutModifiers OptionSet`, `KeyCodeHelper`) using Carbon/CoreGraphics key codes, providing display strings and event matching used throughout the app.
Dependency direction is inward-only: this module depends on Foundation/AppKit/Cocoa/Carbon but is not depended on by sibling app layers except through these singletons and the `Feature` protocol.
