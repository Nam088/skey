KeyboardFeature is the app-level `Feature` entry point that wires three cooperating sub-packages in a one-way data flow: EventHandling captures raw CGEvent taps through EventTapManager and runs them through TypingPipeline stages (KeyInterceptor → KeyEventSender), which delegate to Engine (SKeyEngine/MacroEngine/InputMethod) for Telex/VNI/VIQR rules and macro expansion; the resulting Unicode string plus backspaces are then dispatched by Context (AccessibilityContextReader + ContextRecomposer + VietnameseDecomposer) into the active app via Accessibility APIs. Models (ExcludedApp, MacroItem) are shared data types consumed across layers. Cross-cutting runtime state (engine options, language mode) is exposed as singletons on EventTapManager.shared so other layers do not hold direct references, and UI toggles mutate these setters rather than rebuilding the engine.
