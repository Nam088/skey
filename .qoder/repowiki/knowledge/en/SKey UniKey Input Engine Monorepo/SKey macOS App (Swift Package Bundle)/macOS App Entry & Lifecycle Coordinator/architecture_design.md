Three-file entry point for the macOS app bundle. `main.swift` is the process entry that creates `NSApplication.shared`, assigns an `AppDelegate`, and calls `run()`. `AppDelegate` implements `NSApplicationDelegate` to set up the standard AppKit main menu (App/Edit menus with localized titles via `L10n`), handle launch/terminate/reopen events, listen for cross-process `DistributedNotificationCenter` messages to open settings, and optionally start update checks based on `AppSettings`. `AppCoordinator` is a singleton (`shared`) that owns registered `Feature`s (`KeyboardFeature`, `ClipboardFeature`), configures `StatusBarManager.shared` with those features, wires status icon callbacks between the keyboard feature and status bar, starts focus monitoring via `AppFocusObserver`, syncs launch-at-login state, and runs permission checks through `PermissionsService` before starting features. Dependency direction is one-way: AppDelegate → AppCoordinator → StatusBarManager / Feature implementations; no feature code lives in this module.
