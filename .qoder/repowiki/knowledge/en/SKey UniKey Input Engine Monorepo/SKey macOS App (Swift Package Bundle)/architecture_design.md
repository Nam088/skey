The Swift Package under `macos/skey-app/` is the build root for the SKey `.app`. `Sources/App/main.swift` boots `NSApplication` and hands lifecycle to `AppCoordinator`, which discovers feature modules under `Sources/Features/<Name>` via the shared `Shared/Core/Feature` protocol and starts them. Features communicate only through `Shared/` services — `SettingsStorage` + per-module `*Settings` for configuration, `SKeyLogger` for diagnostics, `LocalizationService` for i18n, `PermissionsService` for system access, and `StatusBarManager` for menu integration — rather than direct cross-feature calls. The Keyboard feature additionally bridges to native code through `CSKey/include/skey.h` and `Support/BridgingHeader.h` to invoke the Rust-backed Vietnamese recomposition engine. Resources (icons, localized strings, `Info.plist`) live in `Resources/` and are packaged into the app bundle alongside the executable built from `Package.swift`; standalone scripts under `scripts/` exercise individual features outside the main process.
