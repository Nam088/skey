Build the full suite by first compiling the Rust workspace (`cd port && cargo build --release --workspace`) to produce `libskey.a`, then building the macOS app from `macos/skey-app` which invokes the script that links `libskey.a`, signs the bundle with the local `SKeyDev` certificate, and installs `/Applications/SKey.app`. Differential tests are run via `cargo test --release -p skey-core` and the Spotlight/Omnibox regression suites under `macos/skey-app/scripts/`.
