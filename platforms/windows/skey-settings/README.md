# SKey Settings

Settings UI sẽ dùng WinUI 3. Cấu trúc feature phản chiếu `macos/skey-app/Sources/Features`:

```text
skey-settings/
├── App/
├── Features/
│   ├── Keyboard/
│   ├── Settings/
│   ├── Clipboard/
│   ├── Translator/
│   └── Cleaner/
├── Shared/
│   ├── Localization/
│   ├── Logging/
│   ├── Services/
│   ├── Settings/
│   ├── Shortcuts/
│   └── UI/
└── Resources/
    ├── Strings/en/
    ├── Strings/vi/
    └── Themes/
```
